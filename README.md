# dsh-api-ledger

DSH 的 API 用量与估算费用账本。默认按 API 路由独立统计；使用者自行设置显示名称、账单分组和计价规则。插件不预设任何企业账户、个人账户或订阅关系。

## 安装

需要 Node.js 20 或以上版本及 DSH Desktop。

```sh
git clone https://github.com/LAwLi3tCoding/dsh-api-ledger.git
cd dsh-api-ledger
node scripts/install.mjs
```

脚本将当前目录链接到 desktop profile，重复执行不会重复注册。重启 DSH 后打开「设置 → API 账本」。其他 profile 可通过 `--profile <name>` 指定。卸载使用 `node scripts/install.mjs --uninstall`。

## 账户与计价

在账本设置页展开「账户与计价」，选择一个路由：

- **显示名称**：默认沿用 DSH 名称，可以修改。
- **账单分组**：可留空。留空时独立展示；相同分组名称会合并报表。分组不代表共用余额或已确认付款主体。
- **模型 ID**：选择已有模型或填写路由实际使用的模型 ID。价格按「路由 + 模型」设置。
- **计价方式**：默认仅记录用量，未配置价格；可明确选择参考价估算或自定义单价估算。
- **自定义单价**：输入、输出、缓存读取、缓存写入分别填写每百万 Token 的价格，并选择 CNY 或 USD。零单价需要显式填写。

当前已配置接口单独展示；只存在于账本配置或历史记录中的接口折叠在「历史与已停用接口」中。可删除已停用接口的账本配置，或重置当前接口的账本配置；操作保留 DSH 模型配置和历史调用。无配置也无历史的接口会从列表消失。

点击「保存此路由」立即生效。名称和分组调整会更新历史报表的展示；价格调整只影响之后的调用。每个模型独立保存，切换模型前请先保存当前修改。

参考价采用 2026-09-21 核对的 [DeepSeek 官方非高峰 USD 价格快照](https://api-docs.deepseek.com/quick_start/pricing/)，不自动判断峰谷时段或中国节假日，不是实时官方报价，不代表代理服务或订阅套餐的实际扣费。只有确认该快照适用时才选择参考模式；其他情况请填写自定义单价或仅记录用量。没有参考价的模型不能选择参考模式，可填写自定义单价。订阅、免费或未知收费规则的接口，建议先使用「仅记录用量」。

不同路由不会因为共享同一个凭据引用就自动合并。插件只读取凭据引用名，不读取或记录密钥值。

## 四处展示

| 位置 | 内容 |
| --- | --- |
| 会话上方 API 账本 Tab | 本会话估算费用、最近调用、模型分布、用量趋势与明细 |
| 设置 → API 账本 | 跨会话报表、周期筛选、今日／昨日对比，以及账户与计价配置 |
| 会话输入框下方 | 当前会话按分组或路由展示的费用 |
| 左下角 | 单行今日费用，点击打开账本设置；悬停查看其他分组 |

默认 CNY，可切换 USD，四处同步并记住选择。折算使用固定 `1 CNY = 0.14 USD`，只改变展示，不修改历史金额。

未定价调用不会显示成免费调用；部分调用未定价时，金额仅代表已计价部分。最近调用显示计价来源；升级前的旧记录标注为历史估算。历史价格和原始币种保存在记录中。

页面可见时每 10 秒更新，隐藏时暂停。一次调用结束并上报用量后才计入。今日与昨日使用客户端本地日历；近 7／30 天按当前时刻回溯。单日记录展示用量构成，多日展示趋势。最近调用默认展示 5 条，可展开至 15 条。

## 本机配置与数据

配置保存在 `$DSH_HOME/api-ledger/config.json`；未设置 `DSH_HOME` 时使用 `~/.dsh/api-ledger/config.json`。这些文件不属于仓库，不能随源码发布。

配置示例（仅作为说明，不会自动生效）：

```json
{
  "labels": { "my-api": "主要接口" },
  "pools": { "my-api": "工作账户" },
  "pricing": {
    "my-api/my-model": {
      "mode": "custom",
      "inputPerM": 1,
      "outputPerM": 2,
      "cacheReadPerM": 0.1,
      "cacheWritePerM": 1,
      "currency": "USD"
    }
  }
}
```

`mode` 支持 `none`、`reference`、`custom`。旧版完整单价对象仍作为自定义价格读取；旧版记录中的分组不再作为报表归类依据，改由本机 `pools` 决定。升级前请把需要保留的旧默认映射和价格写入本机配置。

`records.jsonl` 保存逐次调用的不可变记录；`rollup.json` 是派生汇总。更改分组不会重写记录，更改价格不会重新计算历史金额。当前内存统计最多保留最近 200,000 条记录。

配置保存采用版本检查和原子替换。冲突时重新打开页面再编辑；配置文件损坏时拒绝覆盖并暂停新调用计价。读取支持 RPC 和 HTTP 兼容通道，HTTP 配置写入校验同源、JSON 类型及当前进程令牌。

## 统计边界

- 金额是已记录用量与配置单价的估算，不是余额或供应商账单；不查询预算、额度上限或剩余额度。
- Token 统计包含非缓存输入、输出、缓存读取和缓存写入；推理 Token 不额外重复相加。
- 缓存命中率为缓存读取 /（非缓存输入 + 缓存读取），不包含缓存写入。
- 未上报用量的调用不计入费用；当前运行的缺失次数单独提示，重启后该运行计数不保留。
- 历史缺失的路由、凭据或用量不会被推断补齐。安装之前的调用不会自动补录。
- 嵌套包装调用使用异步上下文去重；一个外层调用扇出多条上游流的情况仍可能漏记，需要额外适配。
